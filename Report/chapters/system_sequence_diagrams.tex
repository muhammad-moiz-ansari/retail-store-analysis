\section{System Sequence Diagrams}
\label{sec:ssds}
Each SSD treats RetailPulse as one black-box system and shows only its external primary actor. Solid arrows are requests or the initial assignment notification; dashed arrows are responses. Combined fragments use \texttt{alt}/\texttt{opt} guards. Internal agents, databases, trackers and LLM calls are intentionally not extra lifelines. These are target interaction specifications, not proof that the complete capability is implemented. The implementation/evidence status remains in Chapter~\ref{ch:req}.

UC-10 and UC-20 apply to both Manager and Employee roles. UC-36 is system-initiated: the supported operational trigger is a note, and the first actor-facing message is the direct employee instruction. No employee request or manager approval is invented to start dispatch. Abbreviated camel-case operation names are conceptual system events, not claims about current endpoint names or schemas.
