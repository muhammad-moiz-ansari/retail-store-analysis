\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Most retail CCTV footage is used only for theft prevention, and small and mid-sized retailers cannot afford specialised analytics hardware or analysts to find out whether customers are being attended to. This report presents \textit{RetailPulse}, a CPU-only system that aims to turn existing CCTV footage into customer-engagement, staff-performance and store-traffic analytics without new cameras. The target business architecture comprises Customer Behavior Agent, Employee Activity Agent, Interaction Agent, Employee Task Assignment Agent, Insight Narration Agent, Query Agent and Orchestrator. Detection/classification/tracking and pose/proximity are shared tools; current implementations and proposed integrations are distinguished in the requirements register. A Next.js dashboard serves managers and employees, with FastAPI and SQLite for application records.

The project follows an iterative approach. At the FYP-1 mid-report stage the web application with role-aware access and an interaction pipeline are implemented. The pipeline combines a trained employee/customer YOLO detector (mAP50 0.969 on 455 held-out images), BoT-SORT tracking, body-height proximity with a pass-by filter, and a YOLO pose judge that evaluates facing evidence while retaining unverified proximity fallbacks. On the one labelled clip the judge raises interaction precision from 0.50 to 1.00; the pipeline ran on all 11 local clips and 44 unit tests pass. A floor-distance prototype was built and then descoped because the moving-camera footage supported almost no floor projections. Dashboard vision metrics still use prototype data. FYP-2 will integrate the vision agents with the dashboard, evaluate them on labelled clips from the supplied videos, and harden the system for the final demonstration.
