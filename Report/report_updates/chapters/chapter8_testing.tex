\chapter{Testing and Early Validation}
\label{ch:testing}
\section{Testing Strategy}
Testing combines functional checks of implemented modules, integration checks across the proxy, backend, and database, security checks of access control, and, in FYP-2, quantitative evaluation of the vision agents against manually labelled clips.

\section{Test Levels and Techniques}
\begin{itemize}
\item \textbf{Unit level:} role/classification, engagement, pass-by, pose-judge, tracking and benchmark-metric checks with known synthetic inputs; the focused floor-geometry, failure-state, smoothing, motion and evaluation checks belonged to the descoped floor prototype.
\item \textbf{Vision CLI integration:} actual trained weights and local video, exported video readability, JSONL invariants and explicit unavailable-state checks.
\item \textbf{Integration level:} frontend to proxy to FastAPI to SQLite for account/application flows.
\item \textbf{System level:} end-to-end use of dashboards, reports and person-analysis outputs.
\item \textbf{Security testing:} direct calls without cookie or secret.
\item \textbf{Vision evaluation:} detector KPIs on a held-out split and interaction precision/recall against labelled clips through \path{backend/interaction/benchmark.py}; broader labelled evaluation continues in FYP-2.
\end{itemize}

\section{Edge and Failure Cases}
\begin{itemize}
\item Staff outside their usual zone or customers in uniform-like clothing, affecting classification.
\item Identity switches during occlusion, affecting dwell and interaction durations.
\item Expired or missing session cookie.
\item Depth ambiguity in the interaction pipeline: people at different depths whose boxes overlap can appear close, and a head turned only slightly can pass the $60^\circ$ facing test (IMG\_8878 at 36\,s).
\item Identity switches on a moving camera split one customer into several track IDs and one interaction into several (IMG\_8881, IMG\_8895).
\item Duplicate/collinear landmarks, invalid homogeneous denominators, incompatible units or frame sizes, stale homography and extrapolation outside calibrated coverage.
\item Lower-frame truncation, manual exclusions, person overlap and seated/occluded feet; box-bottom positions remain proxies.
\item Missing selected tracks, predicted positions, implausible metric jumps and expired reliable observations.
\item Camera shifts, insufficient floor matches or poor spatial spread: preserve unavailable measurements rather than reuse stale alignment.
\end{itemize}

\section{Defects and Corrective Actions}
The first actual tracking run exposed a missing \texttt{lap} assignment dependency; it was installed into the existing virtual environment and declared in backend requirements, after which ByteTrack inference completed. Reference-frame selection was changed to use media timestamps rather than assuming constant-rate timing. A stale-calibration guard and explicit illustrative-config rejection prevent accidental use of incompatible inputs. During the current application checks, the development frontend exhausted a 768\,MB Node heap; it was restarted with a 2048\,MB heap, without modifying application source. The interaction CLI originally appended an active interaction once per scored frame; it now keeps one record per interaction. Annotated videos written while skipping frames keep the source frame rate and play faster than real time; review copies were re-encoded at the true rate. Exhaustive page navigation was not completed. The first unit-test attempt encountered SQLite permission errors in the sandbox temporary directory; using a writable repository-local temporary directory resolved the temporary-directory issue; the corrected-scope rerun subsequently passed 24 tests.

\section{Current Validation Status}
The floor-distance prototype passed its focused synthetic software checks and actual-model/video integration checks before it was descoped. The moving temporary clip supported only the calibration-reference snapshot; the remaining sampled frames were motion-invalid or unverified. The exported quality states distinguish supported approximate positions from unavailable measurements. Trained roles, body-height proximity, duration and the pose judge are now combined in the interaction pipeline, which runs on all 11 local clips; its accuracy is measured on one labelled clip only, and dashboard integration is pending.
