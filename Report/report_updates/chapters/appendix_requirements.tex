\section{Floor-Distance Requirement Priorities and Operator Use Case}
FR-21--FR-26 and FR-28 are high priority; FR-27 is medium priority. NFR-11 applies to all floor-distance paths. UC-14 in Chapter~\ref{ch:req} covers the operator-facing calibration and diagnostic workflow. It supplements existing manager/employee use cases and does not imply that a calibration interface or metric interaction feature is deployed in the web application.
