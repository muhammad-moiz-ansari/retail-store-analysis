\section{Detailed Use Cases}
\subsection*{UC-03: View customer service-quality metrics}
\begin{tabular}{P{0.22\textwidth}P{0.68\textwidth}}
\toprule
Actor & Manager\\
Precondition & Manager is authenticated with a valid session.\\
Main flow & 1. Manager opens Customer Info. 2. System shows footfall, attended versus unattended ratio, response time, and interaction duration. 3. Manager reviews dwell time, shopper-behaviour split, and top paths.\\
Alternative flow & No data for the selected interval: the system shows an empty state.\\
Postcondition & Metrics displayed; no data modified.\\
\bottomrule
\end{tabular}

\subsection*{UC-06: Import POS data}
\begin{tabular}{P{0.22\textwidth}P{0.68\textwidth}}
\toprule
Actor & Manager\\
Precondition & Manager is authenticated. A CSV or XLSX file is available.\\
Main flow & 1. Manager uploads the file. 2. Backend validates and stores the rows in SQLite. 3. Backend computes deterministic metrics, forecasts, and recommendations. 4. The Sales Trends page displays them.\\
Alternative flow & Invalid file or columns: the system rejects the import with an error message and stores nothing.\\
Postcondition & Imported data and derived metrics are available for assistant queries.\\
\bottomrule
\end{tabular}

\subsection*{UC-12: Run camera handoff}
\begin{tabular}{P{0.22\textwidth}P{0.68\textwidth}}
\toprule
Actor & Manager\\
Precondition & Two camera videos are available. Boundaries and thresholds are configured.\\
Main flow & 1. Manager submits a handoff job. 2. System queues it and returns a job id. 3. Manager polls \texttt{/camera/jobs/\{id\}}. 4. System returns confirmed, uncertain, and unmatched associations.\\
Alternative flow & Job fails: the status shows the error.\\
Postcondition & Result JSON is written to the output folder.\\
\bottomrule
\end{tabular}

\subsection*{UC-14: Calibrate and inspect floor distance}
\begin{tabular}{P{0.22\textwidth}P{0.68\textwidth}}
\toprule
Actor & Calibration operator or project team.\\
Precondition & Local video and trained weights exist. Image/floor landmarks or explicitly estimated rectangle dimensions are available.\\
Main flow & 1. Generate the uncalibrated foot-point preview. 2. Select or load ordered landmarks. 3. Save calibration and inspect the grid. 4. Run the distance demo and inspect video, floor map and records.\\
Alternative flow & Missing files, incompatible geometry, invalid calibration, unsupported foot positions or unverified alignment produce actionable errors or unavailable measurements.\\
Postcondition & Local diagnostic files and their configured measurement-status metadata are produced.\\
\bottomrule
\end{tabular}

This operator-facing CLI use case is separate from the manager/employee web interactions shown in the use case diagram; no calibration web page is claimed.

\section{Non-Functional Requirements}
\subsection{Reliability}
NFR-01: The same POS import shall always produce the same metrics (deterministic). NFR-02: Handoff and POS jobs shall report failure states and not fail silently. NFR-11: Floor projection shall reject incompatible frame geometry, stale homographies, invalid homogeneous denominators and unsupported operational coverage. Prediction and smoothing shall not hide alignment failure.
\subsection{Usability}
NFR-03: A manager shall reach any main analytics page within two navigation actions. NFR-04: Charts shall show textual values and use readable fonts (Space Grotesk, Inter, JetBrains Mono).
\subsection{Performance}
NFR-05: The vision pipeline shall run on a CPU-only machine, using frame sampling. NFR-06: Dashboard pages shall render within an acceptable interactive time on a typical laptop. \todo{set measured target after profiling}
\subsection{Security}
NFR-07: Manager POS routes shall require a signed HttpOnly session cookie. NFR-08: Direct backend calls shall require an internal secret header, which the Next.js proxy supplies server-side. NFR-09: Secrets shall be configured through environment variables. NFR-10: No biometric identifiers shall be stored.

\subsection{Floor-Distance Acceptance}
\begin{enumerate}
\item \textbf{Software correctness (FR-21--FR-28, NFR-11):} known synthetic projections and distances agree with expected geometry; invalid cases return an error or unavailable state; illustrative configuration cannot silently serve as actual calibration.
\item \textbf{Integration:} local trained-model/video execution produces readable annotated video, floor maps and timestamped records. Unsupported positions and shifted or unverified frames do not produce supported distances.
\end{enumerate}
