The focused suite is invoked from the repository root with
\begin{quote}\small\ttfamily
.venv/Scripts/python.exe -m unittest\\
\hspace*{1em}backend.tests.test\_floor\_distance -v
\end{quote}
It contains 17 tests. Four existing handoff core regression tests were executed separately using the backend import path. The local coverage evaluation command is
\begin{quote}\small\ttfamily
.venv/Scripts/python.exe scripts/evaluate\_floor\_distance.py\\
\hspace*{1em}--metrics data/outputs/distance/demo/metrics.jsonl\\
\hspace*{1em}--output data/outputs/distance/demo/evaluation.json
\end{quote}
