\chapter{Remaining FYP Plan}
\label{ch:fyp2plan}
\section{Remaining Scope}
Integrate and evaluate the vision agents, orchestrate them with LangGraph, bind real outputs to the dashboard, and prepare the final demonstration. Items listed as out of scope in Chapter~\ref{ch:intro} remain future work.

\section{Remaining Modules and Features}
\begin{itemize}
\item Integrate and evaluate Detection, Classification, Engagement and Trajectory agents; the trained-role floor CLI is already implemented.
\item Integrate supported metric proximity with trained roles and temporal evidence for interaction events, including close pass-bys that are not assistance.
\item LangGraph orchestrator that reconciles per entity.
\item Insight Narration agent over real analytics.
\item Real data in Dashboard, Customer Info, Employee Info, Spatial Analytics, Alerts, and System Status.
\item Improvements to the handoff stage within the committed two-camera scope.
\item Replacement of demo authentication with proper credential handling.
\end{itemize}

\section{Implementation Plan}
Bind agents one at a time to the dashboard, beginning with Detection and footfall, then Classification, Engagement, and Trajectory, keeping prototype data as a fallback until each agent passes its checks. Build the LangGraph graph with explicit state per tracked entity and a defined conflict-resolution rule set.

\section{Testing and Validation Plan}
Label a set of clips for staff/customer, interactions, and zone dwell. Report precision, recall, and error analysis per agent. Re-run Appendix test cases after each integration and record results. Check performance on CPU and record throughput.

\section{Deployment Plan}
The deliverable is a local deployment run with the documented \texttt{npm run dev:all} flow and production build commands (\texttt{npm run build}, \texttt{npm start}). A pilot with a real retail partner is future work.
